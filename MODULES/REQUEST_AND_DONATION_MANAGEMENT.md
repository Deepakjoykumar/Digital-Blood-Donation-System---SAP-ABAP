# Request and Donation Management Module

Track hospital blood requests and donation records.

Reports:
- `ZBD_REQUEST_REPORT` – create, read, update and delete request records.
- `ZBD_DONATION_REPORT` – create, read and delete donation records.

Tables:
- `ZBD_REQUEST`
- `ZBD_DONATION`

The sample demonstrates status tracking in SAP tables. It does not send real-time notifications; a production notification workflow would require approved recipients, authorization, consent and an SAP messaging/integration design.
